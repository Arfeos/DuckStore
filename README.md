como instalar el proyecto en nuestro ordenador

1. Instala **Git** en tu ordenador si todavía no lo tienes.
2. Abre una terminal.
3. Ve a la carpeta donde quieras guardar el proyecto.
4. Ejecuta:

```bash
git clone https://github.com/Arfeos/DuckStore.git
cd DuckStore
```

GitHub confirma que `git clone` crea una copia local completa del repositorio. ([GitHub Docs][1])

5. Comprueba que tienes algo parecido a:

```text
DuckStore/
├── index.html
└── src/
    ├── css/
    └── img/
```


** basta con abrir `index.html` en el navegador**

```text
DuckStore/index.html
```

Puedes hacer doble clic sobre él.

Si quieres ejecutarlo de una forma más correcta como sitio web local, puedes usar un servidor sencillo. Por ejemplo, si tienes Python instalado:

```bash
cd DuckStore
python -m http.server 8000
```

Después abre en el navegador:

```text
http://localhost:8000
```

### Si usas VS Code

Una forma cómoda sería:

```bash
git clone https://github.com/Arfeos/DuckStore.git
cd DuckStore
code .
```

Y desde VS Code puedes instalar **Live Server** y abrir `index.html` con él.
